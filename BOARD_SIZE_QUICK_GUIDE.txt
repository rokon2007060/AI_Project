                        🎮 DRAW RULES EXPLAINED
═══════════════════════════════════════════════════════════════════════════

RULE 1: 40-MOVE RULE
  ┌────────────────────────────────────────────┐
  │ If 40 moves pass WITHOUT any capture      │
  │ → Game is a DRAW                           │
  │                                            │
  │ Counter RESETS when any piece captured    │
  └────────────────────────────────────────────┘

RULE 2: 3-FOLD REPETITION
  ┌────────────────────────────────────────────┐
  │ If the SAME POSITION appears 3 times       │
  │ → Game is a DRAW                           │
  │                                            │
  │ Prevents infinite back-and-forth moves    │
  └────────────────────────────────────────────┘

                        ❓ COMMON QUESTIONS
═══════════════════════════════════════════════════════════════════════════

Q: Can I make a 5x5 board?
A: Not recommended. Minimum 6x6 for proper gameplay.

Q: What's the maximum board size?
A: Technical limit is 20x20, but AI will be VERY slow.

Q: Will my games crash with larger boards?
A: No, but AI thinking time increases exponentially.

Q: Can I disable draw detection?
A: Yes, set MAX_MOVES_WITHOUT_CAPTURE = 9999 and MAX_POSITION_REPEATS = 999

Q: Do draw rules work in all game modes?
A: Yes! Human vs Human, Human vs AI, and AI vs AI.

Q: What if I want faster draws?
A: Reduce MAX_MOVES_WITHOUT_CAPTURE to 20 or 30.
