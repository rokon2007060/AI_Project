EVERY GAME LOOP:

  2. Check if current player has no valid moves → STALEMATE!
     - Player with no moves LOSES
     - Opponent WINS
  3. Check for 40 moves without capture → DRAW

STALEMATE DETECTION:
  - Loops through all pieces of current player
  - Checks valid moves for each piece
  - If total valid moves = 0 → STALEMATE!
  - Opponent declared winner
  - Winner screen displays

═══════════════════════════════════════════════════════════════════════════
                    💡 RULES CLARIFICATION
═══════════════════════════════════════════════════════════════════════════

STALEMATE IN CHECKERS:
  - If a player has pieces but no legal moves
  - That player LOSES
  - Opponent WINS
  - This is standard checkers rules

DIFFERENT FROM CHESS:
  - In chess, stalemate = draw
  - In checkers, stalemate = loss for blocked player

WHAT CAUSES STALEMATE:
  ✓ All pieces completely blocked
  ✓ All pieces trapped in corners
  ✓ No diagonal moves available
  ✓ No captures possible
