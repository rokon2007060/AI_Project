    │  ●  ░░  ●  ░░  ●  ░░  ●  ░░                       │

    Legend:
    ● = Red piece (You in Human vs AI)
    ○ = White piece (AI in Human vs AI)
    ♔ = King piece (can move backward)
    ░░ = Dark square (playable)
    ⊙ = Selected piece
    ◉ = Valid move location (green circle)


                   🤖 AI FEATURES 🤖
    ┌────────────────────────────────────────────────────┐
    │  Algorithm: Minimax with Alpha-Beta Pruning        │
    │  Depth: 3 moves ahead                              │
    │  Thinks: 2-5 seconds per move                      │
    │  Strategy: Evaluates piece count + king value      │
    └────────────────────────────────────────────────────┘


                    📋 GAME RULES 📋
    ┌────────────────────────────────────────────────────┐
    │  1. Red moves first (bottom pieces)                │
    │  2. Move diagonally forward only                   │
    │  3. Jump over opponent to capture                  │
    │  4. Multiple jumps allowed in one turn             │
    │  5. Reach opposite end → Become King ♔             │
    │  6. Kings can move backward                        │
    │  7. Win by capturing all opponent pieces           │
    └────────────────────────────────────────────────────┘


                  🎮 EXAMPLE GAMEPLAY 🎮
    
    Step 1: Click on your piece (Red)
    ┌──────────┐
    │  ⊙  ░░   │  ← Selected piece (highlighted)
    │  ░░  ●   │
    └──────────┘

    Step 2: Green circles show valid moves
    ┌──────────┐
    │  ◉  ░░  ◉│  ← Green circles = valid destinations
    │  ░░  ⊙   │  ← Your selected piece
    │  ●  ░░  ●│
    └──────────┘

    Step 3: Click green circle to move
    ┌──────────┐
    │  ●  ░░   │  ← Piece moved!
    │  ░░  ░░  │
    │  ●  ░░  ●│
    └──────────┘

    Step 4: Capture by jumping
    ┌──────────┐
    │  ●  ░░   │  ← Your piece jumped here
    │  ░░ [X]  │  ← Opponent piece captured (removed)
    │  ░░  ░░  ●│
    └──────────┘

    Step 5: Become King!
    ┌──────────┐
    │  ♔  ░░   │  ← Reached top = crowned King!
    │  ░░  ░░  │  ← Now can move backward too
    └──────────┘
