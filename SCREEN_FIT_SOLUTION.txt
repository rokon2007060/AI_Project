═══════════════════════════════════════════════════════════════════════════
                    🎯 HOW TO FIT YOUR SCREEN
═══════════════════════════════════════════════════════════════════════════

METHOD 1: USE SIZE SELECTION MENU (EASIEST!)
────────────────────────────────────────────
When you run the game:
  1. First screen shows "SELECT WINDOW SIZE"
  2. Press 1, 2, 3, or 4 to choose size
  3. Press ENTER to continue

  OPTIONS:
    1 = Small (500x620)    ← For laptops
    2 = Medium (600x720)   ← RECOMMENDED ✅
    3 = Large (700x820)    ← For big monitors
    4 = Extra Large (800x920) ← For huge screens


METHOD 2: CHANGE FROM MENU ANYTIME
───────────────────────────────────
  1. Press M to return to menu
  2. Select "4. Change Window Size"
  3. Choose your size (1-4)
  4. Press ENTER


METHOD 3: EDIT constants.py (MANUAL)
─────────────────────────────────────
  1. Open constants.py in editor
  2. Find line: BOARD_HEIGHT = 600
  3. Change to: BOARD_HEIGHT = 500 (or any size)
  4. Save and restart game
